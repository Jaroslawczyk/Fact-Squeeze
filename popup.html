Fact Squeeze
выжимка + проверка фактов
Режим
Откройте страницу и нажмите «Сделать выжимку».

История

Сохранённые выжимки доступны после перезапуска Edge.

Настройки

Модель, язык, фактчек и стоимость.

Язык интерфейса и ответа

Интерфейс меняется сразу. Новые ответы ИИ будут на выбранном языке; внутренний анализ может выполняться в более экономном для модели формате.

LLM
Проверка фактов
Это отдельный ключ поиска. DeepSeek/xAI API key сюда не подходит.

Без поискового API расширение может оценить текст, но не может независимо подтвердить факты.

Цена и кэш

Быстрый кэш экономит повторные запросы. История хранится отдельно и не исчезает после этого срока.
