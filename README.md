# Fact Squeeze v0.6.0 — Microsoft Edge

Fact Squeeze делает краткую выжимку открытой страницы, выделяет проверяемые факты, при необходимости сверяет их через веб-поиск и строит отдельные понятные графики для числовых данных и вакансий.

## Что исправлено в v0.6.0

### Графики больше не «ломаются» на точных значениях

В v0.5.x значения вида `5, 5, 4, 0, 0` могли ошибочно рисоваться как диапазоны `min–max`: точное значение `5` превращалось в маленькую точку у правого края шкалы. Теперь логика разделена:

- диапазоны `от–до` рисуются как диапазон;
- обычные числа рисуются как столбики **от нуля**;
- нулевое значение действительно имеет нулевую длину;
- в один график по-прежнему попадают только совместимые единицы измерения.

### Отдельные графики для вакансий

Для листингов JustJoin.it статистика теперь считается локально по реально извлечённым карточкам, без дополнительного LLM-запроса. Если данных достаточно, создаются **отдельные** графики:

1. Прозрачность зарплат — круговая диаграмма: зарплата указана / скрыта / не распознана.
2. Распределение зарплат в PLN/месяц — отдельный столбчатый график по диапазонам `<15k`, `15–20k`, `20–25k`, `25–30k`, `30–35k`, `35k+`.
3. Сравнение конкретных зарплатных вилок — отдельный график диапазонов `min–max`.
4. Профессии / направления — отдельный график: AI/ML, Data/BI, Security, DevOps/Cloud, Frontend, Backend, Full-stack, Mobile, GameDev, QA и т. д.
5. Уровни — отдельная круговая диаграмма Junior / Mid / Senior / Lead / Trainee.
6. Формат работы — отдельная круговая диаграмма Remote / Hybrid / Office.
7. Тип договора — отдельная диаграмма B2B / UoP/Permanent / смешанный вариант / другое.
8. Языки программирования — отдельный столбчатый график Python, Java, JavaScript, TypeScript, C++, C#, Go, Rust и т. д.
9. Технологии и требования — отдельный график AWS, Azure, Docker, Kubernetes, React, TensorFlow, PyTorch, SAP, Terraform и т. д.

Одна вакансия может содержать несколько языков и технологий, поэтому эти частотные графики не притворяются «частями одного пирога».

Ключевой баг v0.5.x также исправлен: массив `jobs`, который извлекался из DOM JustJoin.it, раньше терялся перед этапом аналитики. Из-за этого локальная круговая диаграмма зарплат часто вообще не создавалась. В v0.6.0 карточки передаются дальше корректно.

## DeepSeek API и веб-поиск — это разные ключи

Поле LLM и поле веб-поиска теперь явно разделены.

- **DeepSeek / xAI key** используется для самой выжимки и анализа текста.
- **Tavily key** используется только для независимого веб-поиска при проверке фактов.

Ключ DeepSeek вида `sk-...` нельзя вставлять в поле Tavily. Для Tavily нужен отдельный ключ, обычно `tvly-...`.

В настройках добавлена кнопка **«Проверить веб-поиск»**. Если в поле Tavily вставлен LLM-ключ, расширение сразу объяснит ошибку и не будет тратить запрос.

Также ошибка Tavily больше не уничтожает готовую выжимку: если поиск вернул 401/403/сетевую ошибку, основной анализ всё равно показывается и сохраняется, а фактчек помечается как не выполненный. Ответ ошибки теперь форматируется нормально вместо `[object Object]`.

## История и память

- Каждая новая выжимка автоматически сохраняется в `chrome.storage.local` профиля Edge.
- Закрытие popup, вкладки, Edge или перезагрузка компьютера не удаляют результат.
- При повторном открытии той же страницы последняя сохранённая выжимка показывается без нового расхода токенов.
- Кнопка **«Новая выжимка»** всегда позволяет принудительно обновить данные.
- Хранится до 60 последних выжимок.
- Быстрый кэш и долговременная история работают независимо.

## Языки

Поддерживаются:

- Русский
- English
- Polski

Выбранный язык применяется к интерфейсу и новым ответам ИИ. Внутренние инструкции остаются компактными и не заставляют модель расходовать дополнительные токены только ради «мышления на другом языке».

## Поддерживаемые LLM

- DeepSeek — `https://api.deepseek.com/chat/completions`, модель по умолчанию `deepseek-flash`.
- xAI / Grok — `https://api.x.ai/v1/chat/completions`, модель по умолчанию `grok-4.7`.
- Любой OpenAI-compatible Chat Completions endpoint по HTTPS.

Для DeepSeek thinking отключается для структурированной выжимки, чтобы не расходовать output-токены на скрытые reasoning-токены там, где нужен компактный структурированный ответ.

## Установка / обновление

1. Распакуйте ZIP в постоянную папку.
2. Откройте `edge://extensions`.
3. Включите **Режим разработчика**.
4. Если хотите сохранить существующие ключи и историю, лучше заменить файлы в папке уже установленной unpacked-версии и нажать **Reload / Обновить**.
5. Если устанавливаете впервые — нажмите **Загрузить распакованное расширение** и выберите папку, где находится `manifest.json`.
6. Откройте настройки Fact Squeeze.
7. Укажите LLM-провайдера и LLM API key.
8. Если нужна внешняя проверка, отдельно укажите Tavily API key.
9. Нажмите **Проверить LLM API** и при необходимости **Проверить веб-поиск**.
10. После обновления расширения обновите уже открытые сайты клавишей `F5`.

## Важно про статистику вакансий

JustJoin.it использует динамический список. Браузер может держать в DOM только загруженные/видимые карточки, даже если в заголовке страницы написано, например, `5 650 offers`.

Fact Squeeze не экстраполирует локальные графики на все 5 650 вакансий. Каждый график относится только к реально извлечённой выборке, и это указывается под графиком.

Классификация профессий выполняется локально эвристически по названию вакансии. Это быстрый ориентир, а не официальный taxonomy/filter JustJoin.it.

## Безопасность

API-ключи и история хранятся локально в `chrome.storage.local`. Для личного unpacked-расширения это удобно, но это не серверный vault. Для публичной публикации расширения лучше вынести секретные ключи на собственный backend/proxy.

Если API-ключ когда-либо был опубликован в чате, репозитории или другом открытом месте, рекомендуется отозвать его и создать новый.
